   각 행에 생산 단계(송아지→비육→도축 등)도 함께 표기. 펀치라인:
   "소가 자라는 동안, 양상추는 열다섯 번 자랄 수 있어요".

2. 전체 60초 안에 맞추기 위해 다른 장면 1초씩 조정 (총 57초).

## 구조 (핵심만)

```
SCENES = [{ dur: 5, cap: '자막', draw: scTitle }, ...]  // 7장면, 합 54초
```

- 장면 추가: `draw(t)` 함수 하나 만들고 `SCENES`에 `{dur, cap, draw}` 추가. `t`는 0~1.
- `seg(t, a, b)`: t를 [a,b] 구간 0~1로 자름 — 장면 안 비트 타이밍용.
- `easeOB`: 통통 튀는 착지 / `easeO`, `easeIO`: 기본 이징.
- `jline`, `jellipse`: 손그림 느낌 선/타원. `softShadow`, `sheen`, `face`, `pill`, `numBadge`: v2 질감 헬퍼.
- `drawLayer(i, cx, y, w, faceOn)`: 버거 레이어 6종 (0 아래번 1 양상추 2 토마토 3 치즈 4 패티 5 위번).
- `iconFlour/Beef/Veg/Cheese/Sesame/Sauce`: 재료 카드용 미니 아이콘.
- `LAY`: 레이어 y 오프셋 테이블 (아래→위).
